# Partner Logos Directory

This directory contains logos of partner companies and organizations that are displayed on the AbuBeast platform.

## Logo Requirements:

- Recommended format: SVG or PNG with transparent background
- Recommended size: 200x80px minimum
- File naming convention: company-name.svg or company-name.png

## Adding New Logos:

1. Add the logo file to this directory
2. Update the logo references in the relevant components
